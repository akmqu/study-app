# Student Dashboard

## Main Navigation
Dashboard | Assignments | Payments | Courses

## Dashboard UI
* **Welcome Banner:** Greets the student with a personalized message.
* **Metrics Cards:** 
  * Upcoming assignments (with next due date).
  * This month's payment status (Pending / Paid).
  * Pending reviews (submitted work awaiting tutor feedback).
* **Subjects with Active Tasks:** Card list showing active assignments grouped by subject (e.g., Physics, Mathematics) and their statuses ("To do" or "Awaiting review").
* **Quick Notes:** Personal scratchpad area for the student to save quick reminders.
