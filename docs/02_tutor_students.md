# Students Management & Multi-Tutor Connection

## Connection & Invitation Flow
* **Unified Student Accounts:** A student registers once on the platform and can study with multiple different tutors simultaneously.
* **Invitation System:** 
  * The Tutor generates an invite link/code or inputs the student's existing email.
  * If the student already has an account, accepting the invitation links them to this tutor, adding the new subject/course to their dashboard.

## Student Profile View (Detailed Card)
* **Header Banner:** Displays the student's name, active subjects, and a "Details" button.
* **Progress Tracking:** A visual linear chart (1-100 scale) showing progress based on the last 10 graded assignments.
* **Private Notes:** A secure text area for the tutor's personal notes regarding the student (invisible to the student).
* **Homework Assignment (Direct Action):** Tutors can assign homework directly from this student profile view (similar to the [[01_tutor_dashboard]]), selecting the specific subject, writing instructions, setting a deadline, and attaching files (e.g., PDF, Word).
* **Submissions & Grading:** Tutors can view all homework submitted by this specific student right here, review attached files (including student-uploaded PDFs), leave feedback comments, and assign grades.
