## Dashboard UI & Actions
* **Statistics Cards:** Quick overview metrics (e.g., "Awaiting review", "Active students").
* **Submissions to Review:** A list of pending student homework with a quick "Grade" action button.
* **Assign New Homework (Quick Action):** A form on the dashboard to immediately select a student, write instructions, attach files, and assign tasks.
  * *AI Integration:* Includes an "✨ AI Assistant" button that sends a prompt to the ChatGPT API to automatically generate homework instructions.
