# Student Assignments Module

## Overview (`/student/assignments`)
* Tracks all tasks assigned by different tutors across multiple subjects.

## Task States & Actions
* **To Do:** Displays task description, deadline, attached files, and a "Submit" button to upload completed work (PDF, Word, etc.).
* **Awaiting Review:** Shows that the file has been sent and is waiting for the tutor's grade.
* **Graded / Completed:** Displays the final grade (e.g., A-, 95/100) and tutor feedback comments. Allows "Resubmit" if needed.
