# Calendar & Lesson Scheduling

## Interface
* An interactive weekly/monthly grid where the Tutor schedules lessons.
* Each scheduled slot displays the Student's name and the Subject.
* Supports scheduling recurring lessons.

## Automation & Notifications
* **CRON + Mailpit:** The server automatically checks the schedule every hour and sends email reminders to students who have an upcoming lesson.
* **System Pop-ups:** The Tutor receives in-app notifications for imminent lessons.

## Link to Finances
* The calendar serves as the single source of truth for financial calculations. See [[04_tutor_payments]].
